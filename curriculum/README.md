# Curriculum

Read each chapter's **README first**. It connects the detailed explanations to their runnable examples, optional simpler explanations, and a practice checkpoint.

| Order | Chapter | Focus |
| --- | --- | --- |
| 00 | [Getting started](00-getting-started/README.md) | Hello world, Node.js versus the browser, execution |
| 01 | [Fundamentals](01-fundamentals/README.md) | Variables, types, operators, conditions, loops |
| 02 | [Functions and scope](02-functions-and-scope/README.md) | Functions, the call stack, closures |
| 03 | [Objects and arrays](03-objects-and-arrays/README.md) | Data structures, methods, `this`, prototypes, classes |
| 04 | [Asynchronous JavaScript](04-asynchronous-javascript/README.md) | Callbacks, event loop, promises, async/await |
| 05 | [DOM and browser APIs](05-dom-and-browser/README.md) | Elements, events, JSON, fetch |
| 06 | [Modules and code quality](06-modules-and-quality/README.md) | Modules, debugging, common pitfalls |

Run the chapter guides' commands from the **repository root**, not this folder. Use a supported Node.js LTS release for Node.js examples; use a browser for DOM examples.

The detailed notes contain explanations, execution walkthroughs, common mistakes, and practice. Their Markdown code blocks are independent snippets, sometimes intentionally incorrect; don't concatenate them into a single program. The `examples/` files are standalone scripts unless labeled browser-only.

Java/UI5 comparisons are retained in some scripts for readers who find them helpful. The framework-specific path is separate in the [optional UI5 track](../tracks/ui5/README.md).
