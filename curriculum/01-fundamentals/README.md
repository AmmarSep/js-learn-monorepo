## Practice and checkpoint

Write a loop from 1 to 20 that prints whether each number is even or odd. Then calculate a shopping total and apply a discount only when the total exceeds 100.

- [ ] Choose between `const` and `let` and explain the scope difference from `var`.
- [ ] Explain `null` versus `undefined` and `===` versus `==`.
- [ ] Write a condition and a loop without consulting an example.
