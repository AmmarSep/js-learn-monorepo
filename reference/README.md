# Reference shelf

These are **optional supporting resources**, not another required course. Follow the [main learning path](../README.md), and return here when you need a second explanation or a quick lookup.

| Resource | Use it when… |
| --- | --- |
| [Beginner tutorial](JAVASCRIPT_TUTORIAL.md) | You want slow, symbol-by-symbol explanations with short exercises and answers; chapter guides link to the relevant lessons |
| [Quick reference](QUICK_REFERENCE.md) | You know the concept but have forgotten its syntax |
| [Java-to-JavaScript cheatsheet](CHEATSHEET.md) | You want side-by-side syntax comparisons with Java |
| [Java-to-JavaScript glossary](GLOSSARY.md) | You want to translate familiar Java terminology |
| [Study and review guide](STUDY_GUIDE.md) | You want summaries, self-assessment, suggested pacing, or extra project ideas after studying a chapter |

The tutorial's lesson numbers and the review guide's phase numbers are local to those documents. The **chapter README files** define the repository's recommended order.
The Java cheatsheet and glossary reflect the existing introductory material, not a complete JavaScript reference.

Try snippets separately. Examples illustrating errors or depending on HTML, modules, or an API are not standalone Node.js scripts.
